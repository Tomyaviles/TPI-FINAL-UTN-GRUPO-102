## 📌 Descripción del Proyecto
Sistema web multisede para la administración de gimnasios, diseñado para optimizar el control de socios, cobro de cuotas mensuales, vencimientos automatizados e historial de ingresos en tiempo real.

## 🛠️ Stack Tecnológico
* **Frontend:** Next.js (App Router) + React + TypeScript
* **Estilos / UI:** Tailwind CSS
* **Backend:** Next.js Route Handlers / Server Actions (Node.js)
* **Base de Datos & Auth:** PostgreSQL (Supabase) + Supabase Auth
* **Despliegue:** Vercel (Aplicación) + Supabase (Base de datos)
* **Control de Versiones:** Git + GitHub
